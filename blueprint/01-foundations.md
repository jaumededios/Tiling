## Mathematical model

For a finite subset `F` of an additive commutative group and a function `g`,
the paper's convolution is the finite sum

`(1_F * g)(x) = sum (g (x-f))` over `f` in `F`.

Thus neither summability nor finite support of `g` is needed.  For sets `A,E`,
the equation at level `k` says that points of `E` have exactly `k`
representations `x=f+a`, while points outside `E` have none.  The formal main
theorems make the paper's implicit nonempty-tile convention explicit; without
it, `F=empty` and `E=empty` would make every `A` a vacuous level-one tiling.

Set periodicity is defined by membership rather than by an indicator.  The
equivalence with indicator periodicity is exported once.  This gives a
computationally harmless set API and the integer-valued convolution API needed
by the proofs.

The paper uses the backward difference

`Delta_h f(x) = f(x) - f(x-h)`.

Mathlib already has the forward difference `fwdDiff`; the project defines
only the sign/translation adapter and reuses Mathlib's iteration and
Gregory--Newton results.

## Definitions exported by `Basic`

```lean
namespace TranslationalTilings

abbrev Lattice (d : ℕ) := Fin d → ℤ
abbrev Plane := Lattice 2

noncomputable def setIndicator {G : Type*} (A : Set G) : G → ℤ :=
  A.indicator (fun _ ↦ 1)

noncomputable def tileMonoidAlgebra (R G : Type*) [Semiring R]
    [AddCommMonoid G] (F : Finset G) : AddMonoidAlgebra R G :=
  ∑ f ∈ F, AddMonoidAlgebra.single f (1 : R)

def tileConv {G R : Type*} [AddCommGroup G] [AddCommMonoid R]
    (F : Finset G) (g : G → R) (x : G) : R :=
  ∑ f ∈ F, g (x - f)

def TilesAtLevel {G : Type*} [AddCommGroup G]
    (F : Finset G) (A E : Set G) (k : ℕ) : Prop :=
  ∀ x, tileConv F (setIndicator A) x = (k : ℤ) * setIndicator E x

def Tiles {G : Type*} [AddCommGroup G]
    (F : Finset G) (A E : Set G) : Prop :=
  TilesAtLevel F A E 1

def TilesUniverse {G : Type*} [AddCommGroup G]
    (F : Finset G) (A : Set G) : Prop := Tiles F A Set.univ

def PeriodicOn {G R : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (f : G → R) : Prop :=
  ∀ h ∈ H, Function.Periodic f h

def ScalarPeriodic {d : ℕ} {R : Type*}
    (q : ℕ) (f : Lattice d → R) : Prop :=
  ∀ x z, f (x + (q : ℤ) • z) = f x

def SetPeriodicOn {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (A : Set G) : Prop :=
  ∀ h ∈ H, ∀ x, x + h ∈ A ↔ x ∈ A

def SetScalarPeriodic {d : ℕ} (q : ℕ) (A : Set (Lattice d)) : Prop :=
  ∀ x z, x + (q : ℤ) • z ∈ A ↔ x ∈ A

def IsPeriodic {d : ℕ} (A : Set (Lattice d)) : Prop :=
  ∃ H : AddSubgroup (Lattice d),
    Finite ((Lattice d) ⧸ H) ∧ SetPeriodicOn H A

def addCoset {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (x : G) : Set G := {y | y - x ∈ H}

def quotientCoset {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (c : G ⧸ H) : Set G :=
  {x | QuotientAddGroup.mk' H x = c}

def translateSet {G : Type*} [AddCommGroup G]
    (t : G) (A : Set G) : Set G := {x | x - t ∈ A}

structure WeakPeriodicDecomposition (A : Set Plane) where
  numberOfParts : ℕ
  part : Fin numberOfParts → Set Plane
  period : Fin numberOfParts → Plane
  period_ne_zero : ∀ i, period i ≠ 0
  periodic_part : ∀ i, ∀ x, x + period i ∈ part i ↔ x ∈ part i
  pairwiseDisjoint : Set.PairwiseDisjoint Set.univ part
  iUnion_parts : (⋃ i, part i) = A

def WeaklyPeriodic (A : Set Plane) : Prop :=
  Nonempty (WeakPeriodicDecomposition A)

def OnePeriodic (A : Set Plane) : Prop :=
  ∃ h : Plane, h ≠ 0 ∧ ∀ x, x + h ∈ A ↔ x ∈ A

def CosetwisePeriodic (A : Set Plane) (Λ : AddSubgroup Plane)
    {m : ℕ} (periods : Fin m → Plane) : Prop :=
  ∀ x, ∃ j, ∀ y,
    y + periods j ∈ A ∩ addCoset Λ x ↔ y ∈ A ∩ addCoset Λ x

end TranslationalTilings
```

`WeakPeriodicDecomposition` is proof-relevant public data.  Its parts,
periods, disjointness, and union law are all used in later files.  Conversely,
no choice of coset representatives is stored: `quotientCoset` is the fiber of
Mathlib's canonical quotient map.

## Public theorems exported by `Basic`

```lean
theorem tileConv_apply {G R : Type*} [AddCommGroup G] [AddCommMonoid R]
    (F : Finset G) (g : G → R) (x : G) :
    tileConv F g x = ∑ f ∈ F, g (x - f)

theorem tileConv_zero {G R : Type*} [AddCommGroup G] [AddCommMonoid R]
    (F : Finset G) : tileConv F (0 : G → R) = 0

theorem tileConv_add {G R : Type*} [AddCommGroup G] [AddCommMonoid R]
    (F : Finset G) (g h : G → R) :
    tileConv F (g + h) = tileConv F g + tileConv F h

theorem tileConv_sub {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    (F : Finset G) (g h : G → R) :
    tileConv F (g - h) = tileConv F g - tileConv F h

theorem tileConv_smul {G R S : Type*} [AddCommGroup G]
    [Semiring S] [AddCommMonoid R] [Module S R]
    (F : Finset G) (c : S) (g : G → R) :
    tileConv F (c • g) = c • tileConv F g

theorem tileConv_translate {G R : Type*} [AddCommGroup G] [AddCommMonoid R]
    (F : Finset G) (g : G → R) (a : G) :
    tileConv F (fun y ↦ g (y - a)) = fun x ↦ tileConv F g (x - a)

theorem tileConv_indicator_eq_card {G : Type*} [AddCommGroup G]
    (F : Finset G) (A : Set G) (x : G) :
    tileConv F (setIndicator A) x =
      ((@Finset.filter G (fun f ↦ x - f ∈ A)
        (fun _ ↦ Classical.propDecidable _) F).card : ℤ)

theorem tilesAtLevel_iff_representation_count
    {G : Type*} [AddCommGroup G]
    (F : Finset G) (A E : Set G) (k : ℕ) :
  TilesAtLevel F A E k ↔ ∀ x,
      (@Finset.filter G (fun f ↦ x - f ∈ A)
        (fun _ ↦ Classical.propDecidable _) F).card =
          @ite ℕ (x ∈ E) (Classical.propDecidable _) k 0

theorem periodicOn_mono {G R : Type*} [AddCommGroup G]
    {H K : AddSubgroup G} {f : G → R}
    (hHK : H ≤ K) (hf : PeriodicOn K f) : PeriodicOn H f

theorem setPeriodicOn_iff_indicator {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) (A : Set G) :
    SetPeriodicOn H A ↔ PeriodicOn H (setIndicator A)

theorem setScalarPeriodic_iff_membership {d : ℕ}
    (q : ℕ) (A : Set (Lattice d)) :
    SetScalarPeriodic q A ↔ ∀ x z,
      x + (q : ℤ) • z ∈ A ↔ x ∈ A

theorem finiteIndex_periodic_scalarPeriodic {d : ℕ} {R : Type*}
    (H : AddSubgroup (Lattice d)) (f : Lattice d → R)
    [Finite ((Lattice d) ⧸ H)] (hf : PeriodicOn H f) :
    ScalarPeriodic H.index f

theorem quotientCoset_pairwiseDisjoint {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) :
    Set.PairwiseDisjoint Set.univ (quotientCoset H)

theorem iUnion_quotientCoset {G : Type*} [AddCommGroup G]
    (H : AddSubgroup G) : (⋃ c, quotientCoset H c) = Set.univ

theorem weaklyPeriodic_of_cosetwise (A : Set Plane)
    (Λ : AddSubgroup Plane) {m : ℕ} (periods : Fin m → Plane)
    [Finite (Plane ⧸ Λ)] (hm : 0 < m)
    (hne : ∀ j, periods j ≠ 0) (hmem : ∀ j, periods j ∈ Λ)
    (hA : CosetwisePeriodic A Λ periods) : WeaklyPeriodic A

theorem tiles_translate_tile {G : Type*} [AddCommGroup G]
    (F : Finset G) (A E : Set G) (k : ℕ) (t : G) :
  TilesAtLevel F A E k ↔
      TilesAtLevel
        (@Finset.image G G (Classical.decEq G) (fun f ↦ f - t) F)
        (translateSet t A) E k
```

The last theorem is the normalization bridge: if `t` belongs to `F`, the
translated tile contains zero.  Empty-tile behavior is not hidden.  In
particular `TilesAtLevel empty A E k` is the equation
`0 = k * indicator(E)`, and no main level-one theorem is allowed to infer a
property of arbitrary `A` from that equation.

The three displayed theorem types pass the required classical instances
explicitly.  This keeps the generic group API free of global
`DecidableEq G`, `DecidablePred A`, or `DecidablePred E` assumptions while
still making the occurrence of `Finset.filter`, `Finset.image`, and `if`
well-typed.  The resulting finite sets and branches are independent of the
chosen decision proofs by proof irrelevance; executable algorithms use their
own concrete decidable lattice types instead.

## Definitions exported by `FiniteDifference`

```lean
def backwardDiff {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    (h : G) (f : G → R) : G → R := fun x ↦ f x - f (x - h)

def backwardDiffIter {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    (h : G) (n : ℕ) (f : G → R) : G → R :=
  (backwardDiff h)^[n] f

def lineRestriction {G R : Type*} [AddCommGroup G]
    (f : G → R) (x h : G) : ℤ → R := fun n ↦ f (x + n • h)

noncomputable def eliminationDirections
    {ι G : Type*} [Fintype ι] [DecidableEq ι] [AddCommGroup G]
    (target : ι) (e : G) (period : ι → G)
    (targetCoefficient : ι → ℤ) : List G :=
  (Finset.univ.erase target).toList.map fun i ↦
    e - targetCoefficient i • period target

def applyDifferences {G R : Type*} [AddCommGroup G] [AddCommGroup R]
    (directions : List G) (f : G → R) : G → R :=
  directions.foldr backwardDiff f
```

`FiniteDifference.lean` is the unique owner of `backwardDiff` and
`backwardDiffIter`.  Analytic modules import these declarations; they must not
redeclare namespace-level copies.  This ownership rule is needed because the
structure and polynomial-rigidity modules are imported together downstream.

`eliminationDirections` is noncomputable only because a proof may enumerate a
finite type in an arbitrary order.  No algorithm consumes this list; all
algorithmic data in Chapter 08 use canonical arrays and finite indices.

## Proof content

The convolution identities are `Finset.sum` calculations.  The indicator sum
is the cardinality of a filter after splitting membership in `A`; coercion
injectivity converts the integer equality back to the natural representation
count.  Set periodicity and indicator periodicity are equivalent because the
indicator takes only zero and one.

For finite-index periodicity, Mathlib's index multiplication lemma shows that
`H.index` times every lattice point belongs to `H`; this turns every scalar
multiple into an `H`-period.  Quotient fibers supply a genuinely pairwise
disjoint finite coset partition.  A cosetwise decomposition chooses one of the
finitely many advertised periods on each quotient fiber and groups fibers by
that finite choice.

The finite-difference lemmas unfold through `fwdDiff`; explicitly,
`fwdDiff h f (x-h)=f x-f (x-h)`, so the adapter has no sign change.  For the bounded
constant lemma, induct on the positive difference order.  The first
difference is bounded and has one lower vanishing order, hence is constant by
induction.  A nonzero constant first difference makes
`f(x+n)=f(x)+n*c` unbounded as `n` tends through naturals, so the constant is
zero.  This works for both integer- and real-valued functions.

For `eliminate_periodic_summands`, the direction associated to `i` is
`e-b_i*period(target)=a_i*period(i)`.  Its difference kills summand `i`.
On the target summand the same operator equals `backwardDiff e`, because
`b_i*period(target)` is again a target period.  Difference operators commute,
so the arbitrary `Finset.toList` order is irrelevant.  There is one operator
for every index except `target`, giving exactly `Fintype.card ι - 1`
iterations on the surviving summand.
