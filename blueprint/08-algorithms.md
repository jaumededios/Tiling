## 1. Codes for periodic sets

Use `Fin q`, rather than `ZMod q`, as the stored residue type.  This makes the
finiteness of the representation unconditional at the type-class level; the
positive-period field is used when an integer coordinate is reduced modulo
`q`.

```lean
namespace TranslationalTilings

abbrev BoxResidue (d q : ℕ) := Fin d → Fin q

def boxPoint (x : BoxResidue d q) : Lattice d :=
  fun i ↦ (x i : ℕ)

structure PeriodicSetCode (d : ℕ) where
  period : ℕ
  period_pos : 0 < period
  bits : BoxResidue d period → Bool
deriving DecidableEq

def PeriodicSetCode.memBool
    (C : PeriodicSetCode d) (x : Lattice d) : Bool :=
  C.bits fun i ↦ ⟨(x i).natMod C.period,
    Int.natMod_lt C.period_pos.ne'⟩

def PeriodicSetCode.toSet (C : PeriodicSetCode d) : Set (Lattice d) :=
  {x | C.memBool x}

def PeriodicSetCode.ofBits (q : ℕ) (hq : 0 < q)
    (bits : BoxResidue d q → Bool) : PeriodicSetCode d :=
  ⟨q, hq, bits⟩

def PeriodicSetCode.univ (d q : ℕ) (hq : 0 < q) : PeriodicSetCode d :=
  PeriodicSetCode.ofBits q hq fun _ ↦ true

noncomputable def encodePeriodicSet (q : ℕ) (hq : 0 < q)
    (A : Set (Lattice d)) : PeriodicSetCode d := by
  classical
  exact PeriodicSetCode.ofBits q hq fun r ↦ decide (boxPoint r ∈ A)

def PeriodicSetCode.pullbackTranslate
    (C : PeriodicSetCode d) (a : Lattice d) : PeriodicSetCode d :=
  PeriodicSetCode.ofBits C.period C.period_pos fun r ↦
    C.memBool (boxPoint r + a)

```

`encodePeriodicSet` is intentionally marked `noncomputable`: its input is an
arbitrary mathematical set.  Neither decision procedure calls it.  Algorithm
inputs and search candidates use only `PeriodicSetCode`, whose membership test
is executable.

```lean
theorem PeriodicSetCode.memBool_eq_true_iff (C : PeriodicSetCode d) (x) :
  C.memBool x = true ↔ x ∈ C.toSet

theorem PeriodicSetCode.toSet_scalarPeriodic (C : PeriodicSetCode d) :
  SetScalarPeriodic C.period C.toSet

theorem encodePeriodicSet_toSet
    (q : ℕ) (hq : 0 < q) (A : Set (Lattice d))
    (hA : SetScalarPeriodic q A) :
  (encodePeriodicSet q hq A).toSet = A

theorem PeriodicSetCode.pullbackTranslate_toSet (C : PeriodicSetCode d)
    (a : Lattice d) :
  (C.pullbackTranslate a).toSet = {x | x + a ∈ C.toSet}

```

A code is an actual Boolean table, so its membership operation is the single
table lookup charged by the cost model; it is not a linear search in a
`Finset`.  The counted planar search below generates tables recursively and
proves that it reaches every Boolean function, so this section deliberately
does not expose a `Finset.univ` candidate collection.

### Canonical Hermite-form period-lattice inputs

The following executable Hermite-form code is the **public wire format** for a
finite-index planar period lattice:
the period lattice is generated by `(a,0)` and `(b,c)`, with `a,c>0` and
`0≤b<a`, and a Boolean table records its `a*c` cosets.  The shear range is part
of the input structure, so “Hermite form” here is a checked invariant rather
than an informal promise.

```lean
structure LatticePeriodicSetCode where
  horizontalPeriod : ℕ
  horizontal_pos : 0 < horizontalPeriod
  shear : ℤ
  shear_nonneg : 0 ≤ shear
  shear_lt_horizontal : shear < horizontalPeriod
  verticalPeriod : ℕ
  vertical_pos : 0 < verticalPeriod
  bits : Fin horizontalPeriod → Fin verticalPeriod → Bool
deriving DecidableEq

def LatticePeriodicSetCode.horizontalGenerator
    (C : LatticePeriodicSetCode) : Plane :=
  ![(C.horizontalPeriod : ℤ), 0]

def LatticePeriodicSetCode.verticalGenerator
    (C : LatticePeriodicSetCode) : Plane :=
  ![C.shear, (C.verticalPeriod : ℤ)]

def LatticePeriodicSetCode.periodLattice
    (C : LatticePeriodicSetCode) : AddSubgroup Plane :=
  AddSubgroup.closure
    ({C.horizontalGenerator, C.verticalGenerator} : Set Plane)

def LatticePeriodicSetCode.memBool
    (C : LatticePeriodicSetCode) (x : Plane) : Bool :=
  let verticalQuotient : ℤ := x 1 / (C.verticalPeriod : ℤ)
  C.bits
    ⟨(x 0 - verticalQuotient * C.shear).natMod C.horizontalPeriod,
      Int.natMod_lt C.horizontal_pos.ne'⟩
    ⟨(x 1).natMod C.verticalPeriod,
      Int.natMod_lt C.vertical_pos.ne'⟩

def LatticePeriodicSetCode.toSet (C : LatticePeriodicSetCode) : Set Plane :=
  {x | C.memBool x}

def LatticePeriodicSetCode.scalarPeriod
    (C : LatticePeriodicSetCode) : ℕ :=
  C.horizontalPeriod * C.verticalPeriod

def LatticePeriodicSetCode.toScalarCode
    (C : LatticePeriodicSetCode) : PeriodicSetCode 2 :=
  PeriodicSetCode.ofBits C.scalarPeriod
    (Nat.mul_pos C.horizontal_pos C.vertical_pos) fun r ↦
      C.memBool (boxPoint r)

```

```lean
theorem LatticePeriodicSetCode.toSet_periodic
    (C : LatticePeriodicSetCode) :
  SetPeriodicOn C.periodLattice C.toSet

theorem LatticePeriodicSetCode.scalarLattice_le
    (C : LatticePeriodicSetCode) :
  scalarLattice C.scalarPeriod ≤ C.periodLattice

theorem LatticePeriodicSetCode.toScalarCode_toSet
    (C : LatticePeriodicSetCode) :
  C.toScalarCode.toSet = C.toSet

theorem exists_latticePeriodicSetCode_of_finite_quotient
    (Λ : AddSubgroup Plane) [Finite (Plane ⧸ Λ)]
    (E : Set Plane) (hE : SetPeriodicOn Λ E) :
  ∃ C : LatticePeriodicSetCode,
    C.periodLattice = Λ ∧ C.toSet = E

```

`toScalarCode` is a lazy reindexing of a finite Boolean table, not an eager
materialization of all `scalarPeriod^2` entries.  This chapter makes no public
operation-count claim for this input-format conversion; the counted theorem
below starts with the scalar-period code already supplied.  The scalar
inclusion follows from
`a*c*(1,0)=c*(a,0)` and
`a*c*(0,1)=a*(b,c)-b*(a,0)`.  The coverage theorem is proof-side: classical
Hermite-basis existence and finite-quotient representatives produce a code for
every finite-index lattice-periodic mathematical target, with exactly the same
decoded set.  It may be noncomputable because `E` is an arbitrary `Set`.
Raw generator matrices and their normalization are deliberately outside the
wire-format decision API; this chapter exports neither an executable raw-input
normalizer nor a normalization cost.

## 2. A finite convolution checker with an explicit cost trace

For codes of periods `q_A,q_E`, equality need only be checked on the box of
side `lcm(q_A,q_E)`.  The following counted combinators increment a transparent
unit-cost trace.  The model charges one unit for a Boolean branch or integer
comparison, one per coordinate addition/subtraction or residue reduction, one
for a finite-set membership lookup, and one for incrementing a count.  It does
not claim to model bit complexity or Lean evaluator reductions.

```lean
def countedOr (a b : Bool × ℕ) : Bool × ℕ :=
  (a.1 || b.1, a.2 + b.2 + 1)

instance : Std.Commutative countedOr :=
  ⟨by intro a b; simp only [countedOr]; ext <;>
    simp [Bool.or_comm, Nat.add_comm]⟩

instance : Std.Associative countedOr :=
  ⟨by
    intro a b c
    apply Prod.ext
    · simp [countedOr, Bool.or_assoc]
    · simp [countedOr]
      omega⟩

def countedAnd (a b : Bool × ℕ) : Bool × ℕ :=
  (a.1 && b.1, a.2 + b.2 + 1)

instance : Std.Commutative countedAnd :=
  ⟨by intro a b; simp only [countedAnd]; ext <;>
    simp [Bool.and_comm, Nat.add_comm]⟩

instance : Std.Associative countedAnd :=
  ⟨by
    intro a b c
    apply Prod.ext
    · simp [countedAnd, Bool.and_assoc]
    · simp [countedAnd]
      omega⟩

def countedAdd (a b : ℕ × ℕ) : ℕ × ℕ :=
  (a.1 + b.1, a.2 + b.2 + 1)

instance : Std.Commutative countedAdd :=
  ⟨by intro a b; simp only [countedAdd]; ext <;> omega⟩

instance : Std.Associative countedAdd :=
  ⟨by intro a b c; simp only [countedAdd]; ext <;> omega⟩

def countedAny (s : Finset α) (p : α → Bool × ℕ) : Bool × ℕ :=
  s.fold countedOr (false, 1) p

def countedAll (s : Finset α) (p : α → Bool × ℕ) : Bool × ℕ :=
  s.fold countedAnd (true, 1) p

def countedCount (s : Finset α) (p : α → Bool × ℕ) : ℕ × ℕ :=
  s.fold countedAdd (0, 1) fun x ↦
    let r := p x
    (if r.1 then 1 else 0, r.2 + 1)

def finsetAnyBool (s : Finset α) (p : α → Bool) : Bool :=
  (countedAny s fun x ↦ (p x, 0)).1

def finsetAllBool (s : Finset α) (p : α → Bool) : Bool :=
  (countedAll s fun x ↦ (p x, 0)).1

def PeriodicSetCode.isEmptyBool (C : PeriodicSetCode d) : Bool :=
  finsetAllBool (Finset.univ : Finset (BoxResidue d C.period)) fun r ↦
    !C.bits r

def PeriodicSetCode.memCounted
    (C : PeriodicSetCode d) (x : Lattice d) : Bool × ℕ :=
  (C.memBool x, d + 1)

def periodicTileCountCounted (F : Finset (Lattice d))
    (C : PeriodicSetCode d) (x : Lattice d) : ℕ × ℕ :=
  countedCount F
    (fun f ↦
      let r := C.memCounted (x - f)
      (r.1, r.2 + d))

def periodicTilingPointCounted (F : Finset (Lattice d))
    (A E : PeriodicSetCode d) (x : Lattice d) : Bool × ℕ :=
  let lhs := periodicTileCountCounted F A x
  let rhs := E.memCounted x
  (decide (lhs.1 = if rhs.1 then 1 else 0), lhs.2 + rhs.2 + 2)

def commonCodePeriod (A E : PeriodicSetCode d) : ℕ :=
  Nat.lcm A.period E.period

theorem commonCodePeriod_pos (A E : PeriodicSetCode d) :
  0 < commonCodePeriod A E :=
  Nat.lcm_pos A.period_pos E.period_pos

def tilesPeriodicTargetCounted (F : Finset (Lattice d))
    (A E : PeriodicSetCode d) : Bool × ℕ :=
  let q := commonCodePeriod A E
  let points : Finset (BoxResidue d q) := Finset.univ
  countedAll points
    (fun x ↦ periodicTilingPointCounted F A E (boxPoint x))

def tilesPeriodicTargetBool (F : Finset (Lattice d))
    (A E : PeriodicSetCode d) : Bool :=
  (tilesPeriodicTargetCounted F A E).1

def periodicCandidateCheckCost (d tileCard q : ℕ) : ℕ :=
  q ^ d * (tileCard * (2 * d + 3) + d + 5) + 1
```

The final `+2` in `periodicTilingPointCounted` charges two distinct primitive
operations: branching on the target-membership bit and comparing the resulting
integer with the convolution count.  Thus one tile summand costs `2*d+3`
(subtractions, reductions/table lookup, Boolean-to-natural branch, and fold
addition), the target contributes `d+1`, and the branch, comparison, and outer
fold addition give the displayed exact per-point accounting.  Proof objects,
function closures, projections, and natural-number proof terms are erased and
carry zero cost in this unit-cost model.

```lean
theorem tilesPeriodicTargetBool_eq_true_iff
    (F : Finset (Lattice d)) (A E : PeriodicSetCode d) :
  tilesPeriodicTargetBool F A E = true ↔ Tiles F A.toSet E.toSet

theorem tilesPeriodicTargetCounted_cost_exact
    (F : Finset (Lattice d)) (A E : PeriodicSetCode d) :
  (tilesPeriodicTargetCounted F A E).2 =
    periodicCandidateCheckCost d F.card (commonCodePeriod A E)

theorem tilesPeriodicTargetCounted_cost
    (F : Finset (Lattice d)) (A E : PeriodicSetCode d) :
  (tilesPeriodicTargetCounted F A E).2 ≤
    periodicCandidateCheckCost d F.card (commonCodePeriod A E) :=
  (tilesPeriodicTargetCounted_cost_exact F A E).le

theorem PeriodicSetCode.isEmptyBool_eq_true_iff (C : PeriodicSetCode d) :
  C.isEmptyBool = true ↔ C.toSet = ∅
```

Soundness expands the counted folds.  Completeness translates an arbitrary
lattice point into the common box, using periodicity of both decoded codes and
of their finite convolution.

## 3. Corollary 1.6: deciding whether a planar finite set tiles

For the universe target, candidate and target periods are both `M`.  The search
therefore uses a dedicated same-period checker and performs no `lcm`.  It also
does not obtain a `Finset.univ` of all tables and then attach an informal
generation surcharge.  `searchBoolTablesCounted` is the actual depth-first
binary recursion: at depth zero it yields one table, and at a successor it
executes both possible head bits.  Similarly, `searchPositivePeriodsCounted`
actually visits `1,...,B`; it does not fold over `Finset.Icc`.

```lean
def countedAllRange : (n : ℕ) → (ℕ → Bool × ℕ) → Bool × ℕ
  | 0, _ => (true, 1)
  | n + 1, p =>
      let previous := countedAllRange n p
      let current := p n
      (previous.1 && current.1, previous.2 + current.2 + 1)

def searchBoolTablesCounted :
    (n : ℕ) → ((Fin n → Bool) → Bool × ℕ) → Bool × ℕ
  | 0, check =>
      let result := check (fun i ↦ Fin.elim0 i)
      (result.1, result.2 + 1)
  | n + 1, check =>
      let falseBranch := searchBoolTablesCounted n fun tail ↦
        check (Fin.cases false tail)
      let trueBranch := searchBoolTablesCounted n fun tail ↦
        check (Fin.cases true tail)
      (falseBranch.1 || trueBranch.1,
        falseBranch.2 + trueBranch.2 + 1)

def boolTableSearchCost : ℕ → ℕ → ℕ
  | 0, leafCost => leafCost + 1
  | n + 1, leafCost => 2 * boolTableSearchCost n leafCost + 1

def searchPositivePeriodsCounted :
    (B : ℕ) → ((M : ℕ) → 0 < M → Bool × ℕ) → Bool × ℕ
  | 0, _ => (false, 1)
  | B + 1, check =>
      let previous := searchPositivePeriodsCounted B check
      let current := check (B + 1) (Nat.succ_pos B)
      (previous.1 || current.1, previous.2 + current.2 + 1)

def positivePeriodSearchCost : (B : ℕ) → (ℕ → ℕ) → ℕ
  | 0, _ => 1
  | B + 1, leafCost =>
      positivePeriodSearchCost B leafCost + leafCost (B + 1) + 1

def planarBoxIndex (q : ℕ) (x : BoxResidue 2 q) : Fin (q ^ 2) :=
  ⟨(x 0 : ℕ) * q + (x 1 : ℕ), by
    have hx0 := (x 0).isLt
    have hx1 := (x 1).isLt
    nlinarith⟩

def planarBitsCode (q : ℕ) (hq : 0 < q)
    (bits : Fin (q ^ 2) → Bool) : PeriodicSetCode 2 :=
  PeriodicSetCode.ofBits q hq fun x ↦ bits (planarBoxIndex q x)

def planarBoxPointAt (q i : ℕ) : Plane :=
  ![(i / q : ℕ), (i % q : ℕ)]

def planarShiftedMemCounted (q : ℕ) (hq : 0 < q)
    (bits : Fin (q ^ 2) → Bool) (x f : Plane) : Bool × ℕ :=
  let x0 := (x 0 - f 0).natMod q
  let x1 := (x 1 - f 1).natMod q
  let index : Fin (q ^ 2) := ⟨x0 * q + x1, by
    have hx0 : x0 < q := Int.natMod_lt hq.ne'
    have hx1 : x1 < q := Int.natMod_lt hq.ne'
    simp only [pow_two]
    nlinarith⟩
  (bits index, 7)

def planarTileCountCandidateCounted (F : Finset Plane)
    (q : ℕ) (hq : 0 < q) (bits : Fin (q ^ 2) → Bool)
    (x : Plane) : ℕ × ℕ :=
  F.fold countedAdd (0, 1) fun f ↦
    let r := planarShiftedMemCounted q hq bits x f
    (if r.1 then 1 else 0, r.2 + 1)

def planarTilingPointCandidateCounted (F : Finset Plane)
    (q : ℕ) (hq : 0 < q) (bits : Fin (q ^ 2) → Bool)
    (x : Plane) : Bool × ℕ :=
  let lhs := planarTileCountCandidateCounted F q hq bits x
  (decide (lhs.1 = 1), lhs.2 + 1)

def planarCandidateCheckCounted (F : Finset Plane)
    (q : ℕ) (hq : 0 < q) (bits : Fin (q ^ 2) → Bool) : Bool × ℕ :=
  countedAllRange (q ^ 2) fun i ↦
    let r := planarTilingPointCandidateCounted F q hq bits
      (planarBoxPointAt q i)
    (r.1, r.2 + 2)

def planarCandidateCheckCost (tileCard q : ℕ) : ℕ :=
  q ^ 2 * (9 * tileCard + 5) + 1

def planarTilePeriodCheckCounted (F : Finset Plane)
    (M : ℕ) (hM : 0 < M) : Bool × ℕ :=
  searchBoolTablesCounted (M ^ 2)
    (planarCandidateCheckCounted F M hM)

def planarTilePeriodSearchCost (F : Finset Plane) (M : ℕ) : ℕ :=
  boolTableSearchCost (M ^ 2) (planarCandidateCheckCost F.card M)

def planarTileDecisionCounted (F : Finset Plane) : Bool × ℕ :=
  searchPositivePeriodsCounted
    (periodicTilingPeriodBound F.card (l1Diameter F))
    (planarTilePeriodCheckCounted F)

def planarTileDecision (F : Finset Plane) : Bool :=
  (planarTileDecisionCounted F).1

def planarTileSearchCost (F : Finset Plane) : ℕ :=
  positivePeriodSearchCost
    (periodicTilingPeriodBound F.card (l1Diameter F))
    (planarTilePeriodSearchCost F)

def planarTileSearchExponent (F : Finset Plane) : ℕ :=
  (F.card + 2) *
    (periodicTilingPeriodBound F.card (l1Diameter F) + 2) ^ 4

def planarTileDiameterExponent (tileCard : ℕ) : ℕ :=
  4 * periodicTilingExponent tileCard

def planarTileSearchConstant (tileCard : ℕ) : ℕ :=
  16 * (tileCard + 2) * (periodicTilingConstant tileCard + 3) ^ 4
```

The count is derived structurally from this program.  The primitive table
predicate charges are:

| operation at one point | cost |
|---|---:|
| quotient/remainder used to enumerate the point | `2` |
| two coordinate subtractions and two residue reductions | `4` per `f∈F` |
| row-major index multiplication/addition and table lookup | `3` per `f∈F` |
| Boolean-to-natural membership branch and counter addition | `2` per `f∈F` |
| initialize the tile counter and compare it with one | `2` |
| combine the point with the range accumulator | `1` |

Thus one point contributes `9*F.card+5`, and initializing the range contributes
the last `+1` in `planarCandidateCheckCost`.  At a Boolean-search leaf the
program charges one table-yield operation.  At an internal node it charges the
Boolean `or`; hence `boolTableSearchCost n C + 1 = 2^n*(C+2)`.  The period
recursion has one initial operation and one `or` per visited positive period.
It passes `Nat.succ_pos B` to the period checker, so there is no uncharged
`if 0<M` branch.
There are no list constructors, hidden `Finset.univ` materializations, `lcm`
calls, or manually injected generation surcharges in this counted search.

```lean
theorem countedAllRange_cost (n : ℕ) (p : ℕ → Bool × ℕ) :
  (countedAllRange n p).2 =
    1 + ∑ i ∈ Finset.range n, ((p i).2 + 1)

    boolTableSearchCost n leafCost

theorem boolTableSearchCost_closed (n leafCost : ℕ) :
  boolTableSearchCost n leafCost + 1 = 2 ^ n * (leafCost + 2)

theorem searchPositivePeriodsCounted_eq_true_iff (B : ℕ)

  (searchPositivePeriodsCounted B check).1 = true ↔
    ∃ (M : ℕ) (hM : 0 < M), M ≤ B ∧ (check M hM).1 = true

    (hcost : ∀ M (hM : 0 < M), M ≤ B →
      (check M hM).2 = leafCost M) :

theorem planarCandidateCheckCounted_eq_true_iff

theorem planarCandidateCheckCounted_cost

theorem planarTilePeriodCheckCounted_cost

theorem planarTileDecision_eq_true_iff (F : Finset Plane) :
  planarTileDecision F = true ↔ ∃ A : Set Plane, TilesUniverse F A

theorem planarTileDecisionCounted_cost_exact (F : Finset Plane) :
  (planarTileDecisionCounted F).2 = planarTileSearchCost F

theorem planarTileDecisionCounted_cost (F : Finset Plane) :

theorem planarTileSearchCost_eq_sum (F : Finset Plane) :

  planarTileSearchCost F =
    1 + ∑ k ∈ Finset.range B,
      2 ^ ((k + 1) ^ 2) *
        ((k + 1) ^ 2 * (9 * F.card + 5) + 3)

  let B := periodicTilingPeriodBound F.card (l1Diameter F)
  planarTileSearchCost F ≤
    1 + B * (2 ^ (B ^ 2) * (B ^ 2 * (9 * F.card + 5) + 3))

  planarTileSearchCost F ≤ 2 ^ planarTileSearchExponent F

theorem planarTileSearchExponent_diameter_bound (F : Finset Plane) :
  planarTileSearchExponent F ≤ planarTileSearchConstant F.card *
    max 1 (l1Diameter F ^ planarTileDiameterExponent F.card)

theorem planarTileDiameterExponent_le_quartic (tileCard : ℕ) :
  planarTileDiameterExponent tileCard ≤ 12 * (tileCard + 1) ^ 4

example : periodicTilingPeriodBound 0 0 = 1 := by decide

example :
    planarTileDecisionCounted (∅ : Finset Plane) = (false, 17) := by

example : planarTileSearchCost (∅ : Finset Plane) = 17 := by
  decide
```

The first theorem is sound by decoding.  For completeness, Theorem 1.5 gives
a period multiplier `M≤B`; that candidate occurs in the positive-period
recursion.  If
`B=periodicTilingPeriodBound c D`, the recursive loop visits exactly the
positive periods at most `B` and exactly `2^(M^2)` Boolean tables at period
`M`.  Expanding the two recurrences gives `planarTileSearchCost_eq_sum`;
monotonicity of `M↦2^(M²)` and of the polynomial predicate cost gives
`planarTileSearchCost_preclosed_bound`.  Finally, for `B≥1`, elementary natural
arithmetic bounds its right side by
`2^((c+2)*(B+2)^4)`; the `B=0` branch is immediate.  This is exactly
`planarTileSearchCost_closed_bound`, rather than a reuse of the former fold
estimate.  Substitution of
`B≤C(c)*max(1,D^periodicTilingExponent(c))` gives the displayed diameter
bound.  Thus the result is exactly `exp(O_c(D^O(c^4)))` in the paper's
unit-cost arithmetic model, while making no claim about bit complexity.

## 4. Normalizing the finite tile for the uniform classifier

The structural theorem uses a tile containing zero.  To avoid the
noncomputable `Finset.toList`, the executable anchor is the lexicographically
least image of the tile in `ℤ ×ₗ ℤ` (and zero only in the empty case).

```lean
def tileAnchor (F : Finset Plane) : Plane :=
  if hF : F.Nonempty then
    pairToPlane ((F.image planeToPair).min' (hF.image planeToPair))
  else 0

def normalizedTile (F : Finset Plane) : Finset Plane :=
  F.image fun f ↦ f - tileAnchor F
```

## 5. A genuinely finite tuple enumeration

Put `F0=normalizedTile F`.  The direction list is the canonical list from
Chapter 6.  The weak multiplier is a positive integer bounded by
`weakPeriodMultiplierBound`; it is therefore stored in a `Fin (B+1)`.  All
fully periodic representatives can be lifted to the single period

`P = E.period * (periodicTilingPeriodBound |F| diam(F))!`.

If a representative originally has multiplier `M≤B`, then `M∣B!`, so it is
also `P Z^2`-periodic.  Consequently every tuple payload is a function from a
fixed finite direction type to one Boolean table on a fixed finite box.

## 6. Executable chameleon-slice test

The following coordinate routine decides whether `z` is an integer multiple
of a nonzero vector and, if so, returns the multiplier.  It tests the first
nonzero coordinate and verifies the full vector equality.

```lean
def multipleCoordinate? (v z : Plane) : Option ℤ :=
  if _hv0 : v 0 ≠ 0 then
    let n := z 0 / v 0
    if z = n • v then some n else none
  else if _hv1 : v 1 ≠ 0 then
    let n := z 1 / v 1
    if z = n • v then some n else none
  else none

def classifierLinePeriod (F : Finset Plane) (E : PeriodicSetCode 2)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) : ℕ :=
  E.period * T.weakMultiplierNat * vectorContent (classifierDirection F j)

def linePatternMemBool (v y : Plane) (period : ℕ) (hperiod : 0 < period)
    (P : LinePattern period) (x : Plane) : Bool :=
  match multipleCoordinate? v (x - y) with
  | none => false
  | some n => P ⟨n.natMod period, Int.natMod_lt hperiod.ne'⟩

def referenceSliceMemBool
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) (y x : Plane) : Bool :=
  (T.representativeCode j).memBool x &&
    (multipleCoordinate? (classifierPrimitiveDirection F j) (x - y)).isSome

def linePatternTileCount (F : Finset Plane) (v y : Plane)
    (period : ℕ) (hperiod : 0 < period) (P : LinePattern period)
    (x : Plane) : ℕ :=
  (F.filter fun f ↦ linePatternMemBool v y period hperiod P (x - f)).card

def referenceSliceTileCount (F : Finset Plane)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) (y x : Plane) : ℕ :=
  (F.filter fun f ↦ referenceSliceMemBool T j y (x - f)).card

def lineCheckPeriod (F : Finset Plane) (E : PeriodicSetCode 2)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) : ℕ :=
  Nat.lcm (classifierLinePeriod F E T j) (classifierPeriod F E)

def differentLinePatternBool (F : Finset Plane) (E : PeriodicSetCode 2)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) (y : Plane)
    (hk : 0 < classifierLinePeriod F E T j)
    (P : LinePattern (classifierLinePeriod F E T j)) : Bool :=
  let Q := lineCheckPeriod F E T j
  finsetAnyBool (Finset.univ : Finset (Fin Q)) fun n ↦
    linePatternMemBool (classifierPrimitiveDirection F j) y
        (classifierLinePeriod F E T j) hk P
        (y + (n : ℕ) • classifierPrimitiveDirection F j) !=
      referenceSliceMemBool T j y
        (y + (n : ℕ) • classifierPrimitiveDirection F j)

def equivalentLinePatternBool (F : Finset Plane) (E : PeriodicSetCode 2)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) (y : Plane)
    (hk : 0 < classifierLinePeriod F E T j)
    (P : LinePattern (classifierLinePeriod F E T j)) : Bool :=
  let Q := lineCheckPeriod F E T j
  finsetAllBool F fun f₀ ↦
    finsetAllBool (Finset.univ : Finset (Fin Q)) fun n ↦
      let x := f₀ + y + (n : ℕ) • classifierPrimitiveDirection F j
      linePatternTileCount F (classifierPrimitiveDirection F j) y
          (classifierLinePeriod F E T j) hk P x ==
        referenceSliceTileCount F T j y x

def hasChameleonSlice (F : Finset Plane) (E : PeriodicSetCode 2)
    (T : RepresentativeTupleCode F E)
    (j : Fin (classifierDirectionCount F)) : Bool :=
  if hk : 0 < classifierLinePeriod F E T j then
    finsetAnyBool
      (Finset.univ : Finset (BoxResidue 2 (classifierPeriod F E))) fun y ↦
      finsetAnyBool (Finset.univ : Finset
        (LinePattern (classifierLinePeriod F E T j))) fun P ↦
          differentLinePatternBool F E T j (boxPoint y) hk P &&
            equivalentLinePatternBool F E T j (boxPoint y) hk P
  else false
```

The finite test points are complete.  Both convolutions are periodic along the
primitive line with period `lcm(k,P)`.  If either convolution is nonzero at
`x`, then `x=f+y+n*v` for some `f∈F`; hence the loops over `f` and one full
longitudinal period see it.  Every line is a `P Z^2` translate of a line whose
base point lies in the `P×P` box, so the outer loop sees every reference slice
type.

## 7. Classification of all tilings

The finite tuple is only the periodic background.  Describing an individual
tiling still requires one finite line pattern on each of infinitely many
lines.  That infinite choice is represented mathematically below and is not
misrepresented as a finite executable enumeration.

```lean
structure LineSelection (F : Finset Plane) (E : PeriodicSetCode 2)

  supported : ∀ j line,
```

For the forward direction, Chapter 6 provides the uniformly bounded `L` and
canonical directions.  Chapter 7 improves each component separately.  Lift
all representatives to `classifierPeriod`, then retain on every primitive
line the original finite periodic pattern.  Conversely, sum the linewise
convolution identities.  The valid-tuple equation gives `1_E`; since `F` is
nonempty, the resulting nonnegative pointwise sum is at most one, so all
selected pieces are disjoint and their union is a level-one tiling.

The proof of the final iff follows the program branches in order.  If `F=∅`,
the theorem's `hF` hypothesis closes the branch immediately; the total Boolean
program returns `false` there but makes no unrestricted correctness claim for
an empty tile and empty target.  If `F.card=1`, a tiling complement is a
translate of the periodic target and is one-periodic.  If `E.isEmptyBool`, its
decoded set is empty and nonempty `F` forces `A=∅`, again one-periodic.  Only
the residual branch has `F.Nonempty`, `1<F.card`, and `E.toSet.Nonempty`, so it
normalizes exactly once and invokes the chameleon classifier with all its
hypotheses available.  The lattice-input theorem first applies the proved
`toScalarCode_toSet` equality and then follows these same branches.

For two chameleons, replace one line in each of two incommensurable directions.
The difference from the periodic background is the sum of two nonzero
periodic functions supported on two nonparallel affine lines.  A translation
preserving that sum must preserve each directional family, hence is parallel
to both lines and is zero.  If the constructed tiling had period `u≠0`,
multiplying `u` by the background scalar period would give a nonzero period of
the difference, a contradiction.

If at most one direction is chameleonic, all other selected components equal
their fully periodic representatives.  A common scalar period of those
representatives, multiplied by the sole variable direction, is a nonzero
period of their disjoint union.  The finite tuple classification makes these
two cases exhaustive.

## Recursive prerequisites introduced by this chapter

The implementation must prove, in dependency order:

1. reduction of decoded periodic convolution equality to a common finite box;
2. the trace bounds for the three counted finite-set folds;
3. soundness, completeness, and exact trace recurrences for the recursive
   range, Boolean-table, and positive-period searches;
4. completeness of the factorial lift of bounded periods;
5. the proof-side coverage theorem for the checked Hermite wire format, and
   lazy scalar-code conversion for an already normalized code (raw generator
   normalization is outside this decision API);
6. executable normalization and translation of the target code;
7. the singleton-tile and empty-target periodicity lemmas;
8. the uniform directional-decomposition constructor from Chapter 6 data;
9. sufficiency of the finite longitudinal convolution test;
10. finite-box coverage of all slice types;
11. line-selection assembly and level-one disjointness for nonempty `F`;
12. the support geometry for two changed nonparallel lines.

No external computability framework, generic cost model, or classical
enumeration lemma is assumed.
